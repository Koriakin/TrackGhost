\# TrackGhost

DIY мотосимулятор: Teensy 4.1, датчики Холла, актуаторы 1500 Н. Наклоняющаяся платформа с обратной связью от игры. Механика, электроника, прошивка — всё с нуля.

## Статус проекта

- [x] Закуплена электроника
- [x] Базовый код чтения датчиков (протестирован в Wokwi)
- [ ] Механическая сборка рамы
- [ ] HID-интеграция (отправка осей в ПК)
- [ ] Обратная связь от актуаторов
- [ ] Парсинг телеметрии из игры

## Команда

- **Техник** — механика, электроника, сборка
- **Программист** — прошивка Teensy, парсинг телеметрии

## Как это работает

1. Райдер наклоняет корпус — IMU и датчики Холла считывают положение.
2. Teensy 4.1 отправляет данные в ПК как USB HID геймпад.
3. Игра наклоняет мотоцикл и меняет траекторию.
4. Телеметрия из игры возвращается на Teensy.
5. Два актуатора на 1500 Н создают сопротивление и помощь при наклоне.

## Стек

| Компонент | Модель |
| :--- | :--- |
| Контроллер | Teensy 4.1 |
| Датчики положения | SS49E (Hall) |
| Датчик наклона | MPU-6050 |
| Актуаторы | 12 В, 1500 Н, ход 250 мм |
| Драйверы | BTS7960 |
| Питание | Mean Well LRS-600-12 |
